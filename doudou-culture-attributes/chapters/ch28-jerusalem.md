# 第28章 耶路撒冷

## 核心思想
四份代理协议与两套卖出的音响，把欧洲这件事画上句号。而在耶路撒冷，丁元英把全书的核心命题又推了一层：知道道理的人很多，但道理只是条件，用才有用；不是我希望你成为哪种人，而是你本该成为哪种人——那是条件的可能，因果不虚。三教圣地的苦难则给出了最直白的证明：原本就没什么救主。

## 框架 / 原则
- **自觉与觉他**：「你的知道是自觉，现在是让你觉他……道理和知识是没用的，只是有用的一个条件，用才有用。」
- **本该成为哪种人**：不是天命，而是「条件的可能，因果不虚，因果是规、是律，不可思议」。
- **不可思议的真实含义**：他用抛打火机做实验——接住是本能，来不及思议；「规律不以人的意志为转移，你只能认识、遵循」。
- **聪明与智慧**：她的自问——叶晓明、冯志杰、刘冰「只要有丁元英就行了……他们知道用了一个丁元英也就用了他的知识、智慧和社会关系」，那是聪明；「聪明与智慧在多大程度上能兼容呢？」
- **救主的缺席**：在打了五十年的巴以冲突面前——「上帝和真主都没能拯救他们，世界上再没有什么地方能像这里让人明白这个真理真相」。

## 关键概念
- **四份代理协议**：柏林斯雷特姆（欧洲总代理）、柏林格尔斯勒（德国）、伦敦梅洛林（英国）、巴黎诺尔圣西（法国）。
- **两套卖出的音响**：格贝森与辛格各买一套——「花 8000 马克的钱去买 3 万马克的音质享受」。
- **头上安头，妇人之见**：丁元英对詹妮委托杂志社搞主观测评的评价。
- **洗碗工**：她在母亲店里顶了八天洗碗的岗位，每天十一个小时，用劳累压住思念。
- **哭墙上的祈祷词**：她写下的只有一句——「亲爱的，上帝赐予你快乐！」

## 心智模型
- 用忙碌压住心苦：把体力和时间填满，脑子就没空。
- 用实验代替论证：抛接打火机，比长篇解释更能说明「不可思议」。
- 用条件解释选择：不问「谁更该成为什么人」，只问「条件允许他成为什么」。
- 用提问收尾：如果你是上帝，面对耶路撒冷你会怎么样？

## 反面模式
- **把知识当能力**：道理和知识只算条件，不构成结果。
- **把测评当目的**：主办方与杂志社都在借这台戏赚钱，戏做过头就偏离了本意。

## 实例还原
这一章有三组场景。

**其一：法兰克福收尾**

1. **等待**：她在洗碗间等郑建时的电话，等到的那一刻，意味着德国的事全办完。
2. **交割**：四份代理协议、现场照片、一万六千马克当面交代。
3. **插曲**：詹妮追加专家测评，郑建时担心「这戏做过头了还是不是元英的本意」。
4. **母亲的态度**：挂出招工牌子，「事情办完就早点回去吧」。

**其二：网上密谈**

1. **她要回国**：「我一分钟都等不及了。」
2. **他不同意**：「你探亲的目的就是陪你母亲。」
3. **转折**：他已订好北京到特拉维夫的机票，在特拉维夫等她——「『我想你了』和『必要信息储备』两条思路不必矛盾，它们的交汇点就在耶路撒冷」。

**其三：耶路撒冷**

1. **初见**：他拎着一个塑料袋当行李，出国旅游的全部装备。
2. **谈觉**：从「自觉」到「觉他」，从道理到使用。
3. **实验**：抛打火机，说明规律不容思议。
4. **提问**：炸弹若在此刻爆炸会怎样——「那时爱就永恒了」；「存在和永恒我都能接受，有没有又有什么分别？」
5. **哭墙**：她按规矩写下祈祷词，塞进石缝，念的是同一句话。

## 要点
1. 智慧不是知道得多，而是能把条件用出来。
2. 规律不容争辩，只能认识与遵循。
3. 聪明的人常常借别人的智慧办事，但借来的东西需要还。
4. 三教圣地最能说明的，恰恰是救主并未降临。
5. 爱与永恒的选择题，答案在于你是否接受结果本身。

## 关联
- **第20章**：五台山谈的是「得救之道」，耶路撒冷谈的是它为何必要。
- **后续**：欧洲文件齐备，格律诗的身价有了凭据，北京的正面交锋即将开始。
