# 第2章 柏林清算会

## 核心思想
私募基金在十一个月、82% 回报率的高点上被丁元英单方面终止。投资人怀疑他「存有不道德商业动机」，依据协议第二十一条冻结他的资本；他既不解辩也不抗争，而是划掉补偿条款、只留十三万六千马克饭钱，用动作代替论证。

## 框架 / 原则
- **规则高于情绪**：詹妮一边按规矩冻结他的钱，一边用路易十三为他饯行——「我只能按规矩办」。用法：契约关系里，把感情与条款分开执行，两件事互不抵消。
- **风险定价**：担保方承担损失风险，换走收益的大头。十一个月里担保方回报率 239.7%，投资委托方 50.35%，受托人自己 513.6 万马克——超额收益属于承担风险的一方。
- **对「不道德动机」条款的反制**：不靠辩解，而是主动放弃本可拿的补偿，降低对方怀疑你的动机。
- **结果建立信任**：詹妮说「你让我们都赚到了钱，这才是本质」——信用由结果累积，不由交情决定。

## 关键概念
- **受托资本 / 担保金 / 委托资本**：基金的三方结构，共十一名当事人。
- **第二十一条担保条件条款**：受托方在盈利看好且已积累千万元以上时单方终止合作，经三分之二以上资本代表表决认定其存有不道德商业动机，担保方有权冻结受托方资本二到三年。
- **取款机**：投资方代表格尔斯曼对中国股市的比喻——掌握「文化密码」的人可以开箱取钱。
- **法律上的真空地位**：未注册、无立法，投机而尴尬，「不适合男婚女嫁」。

## 心智模型
- 把「为什么现在停」当成本质问题：在收益最盛时退出，最容易被读成动机不纯，必须预估这个解读。
- 用让渡利益来证明动机：与其解释，不如放弃本可拿的钱。
- 把自己放在「不重要」的位置——「我这个人还没有重要到可以用个人声誉来评价的程度」，减少对方攻击的支点。

## 反面模式
- **预先谋划的封口协议**：投资人带着现金和拟好的协议进场要求签字，被郑建时当场点破「这显然是预先谋划的」。用规则施压可以，把算计摆上桌面就失了体面。
- **把盈利高峰当作继续的理由**：路再好也要看退出条件，「私募基金是从狼嘴里夹肉，得适可而止」。

## 实例还原
第二十一条表决与丁元英的应对：

1. **触发**：格尔斯曼质疑终止合作是否受到外力作用，并援引协议要求表决。
2. **表决**：七票支持、三票反对（担保方中只有郑建时举手支持），资本冻结通过。
3. **加码**：恩格要求他签署五年竞业限制，并当场备好十八万马克现金（六家投资方各三万）。
4. **反制**：丁元英划掉补偿条款后签字，只请求从被冻结的资金里留十三万六千马克作饭钱。
5. **效果**：格尔斯曼只能说「我想，我们没有理由不同意」；全场的疑问从「有没有道德问题」变成「为什么」。
6. **事后**：詹妮按规矩办完冻结，也按规矩上好酒饯行，并讲明信任的依据是收益而不是交情。

## 要点
1. 在契约社会里，朋友也会严格执行对你不利的条款。
2. 承担风险的人拿走大头收益，这是结构，不是人情。
3. 面对动机质疑，让渡利益比辩论有效。
4. 终止合作这件事本身就是一个信号，要预估它会被怎样解读。

- **第3章**：格尔斯曼口中的「文化密码」，将在北京的酒桌上被正式命名为「文化属性」。
